# unity-3d-model-tool

Standalone Unity UPM package for prompt-based 3D generation in Blender and automatic Unity import.

## Package Path
- `package/com.aslan.modeltool`

## Features
- Prompt + Count based model variants
- Blender batch generation (`.fbx`)
- Auto import settings for performance
- Optional prefab creation and collider setup

## Unity Menu
- `Tools/Aslan 3D Model Tool/Open Tool`
- `Tools/Aslan 3D Model Tool/Open Settings`
